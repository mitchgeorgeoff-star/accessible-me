# Accessible Me

This project focuses on improving accessibility for a basic HTML/CSS landing page by fixing semantic structure, adding skip links, improving contrast, and adding schema markup.

## Project goals
- Fix repeated heading and layout issues
- Add accessible form labels and keyboard-friendly focus states
- Improve contrast for readability and clarity
- Provide a polished but still accessible experience for screen-reader and keyboard users
